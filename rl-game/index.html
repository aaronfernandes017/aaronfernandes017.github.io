Reward settings

Campaign score comes from rallies. The agent uses these rewards to learn which moves are useful.

Train the agent

A 490-state Q-table (49 squares × 10 collected-rally counts) starts at zero. It learns with ε = 0.2, learning rate = 0.2, discount = 0.95, and a fixed random seed. Watch mode makes no exploratory moves.
